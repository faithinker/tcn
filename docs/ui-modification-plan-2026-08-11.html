작업 1

텍스트 입력: 이중 테두리 제거

우선순위 P1

입력창 크기와 형태는 고정하고 테두리 색만 바꾼다. 포커스 때 기존 검정 border와 파란 outline이 겹치는 현상을 없애고, 하나의 선으로 상태를 전달한다.

권장 상태 모델

  1. Normal: hairline 중립색. 가장 조용한 상태.
  2. Hover: warm ink. 클릭 가능한 영역임을 예고.
  3. Focus: institutional blue. 단일 2px 선, 추가 outline 없음.
  4. Filled: 별도 선택 상태로 보지 않음. 값이 있어도 normal 규칙 유지.
  5. Error: danger 색. 포커스보다 오류 의미를 우선하고 메시지 병기.
상태 선 보조 변화
Normal #ddd9d0 없음
Hover #2e2a22 150ms 색 전환
Focus #0b3d6b caret와 label도 accent 가능
Error #8a2b1f aria-invalid + 오류 문구
권장 시안

원인: src/pages/questions/new.astro의 field border와 src/styles/global.css의 전역 :focus-visible outline 중첩. 수정 대상: 두 Q&A 입력에 공용 field 클래스를 주고 form control에서만 전역 outline을 단일 focus border로 치환. 키보드 포커스 식별성은 유지.

완료 조건

  • 마우스·키보드 포커스 모두 파란 선 하나만 보임.
  • 상태 전환 때 입력창 크기 또는 주변 레이아웃이 움직이지 않음.
  • Title input과 Question textarea가 같은 상태 규칙 사용.
  • light/dark theme에서 normal·hover·focus·error가 구분됨.

작업 2

헤더 메뉴: 순서와 상호작용 대비

우선순위 P2

데스크톱 순서를 로고 → 주요 메뉴 → Join / Contact → 테마 버튼으로 바꾼다. 활성 메뉴는 파란 글자와 하단 선, 호버는 옅은 paper 배경과 밝은 파란 글자로 구분한다.

변경 규칙

  • 테마 버튼을 헤더 가장 오른쪽 끝으로 이동.
  • Normal: ink 텍스트, 배경 없음.
  • Hover: canvas-soft 배경 + accent-hover 텍스트.
  • Active: accent 텍스트 + 2px 하단선. 색만으로 상태를 구분하지 않음.
  • Focus-visible: 키보드 outline 유지. hover와 focus를 같은 상태로 취급하지 않음.
  • About 드롭다운 open 상태도 active 계열과 같은 어휘 사용.
데스크톱 순서 시안
Transcultural Network Home About⌄ People Seminars Q&A Join / Contact

수정 대상: src/components/Header.astro. 현재 ThemeToggle을 담은 컨트롤 그룹이 order-2, nav가 order-3라 버튼이 메뉴 앞에 나타남. 데스크톱과 모바일 DOM/탭 순서가 시각 순서와 일치하도록 구조 자체를 정리.

완료 조건

  • 1152px 이상에서 테마 버튼이 가장 오른쪽.
  • 896–1151px 압축 헤더에서도 메뉴 겹침 없음.
  • 현재 페이지·호버·키보드 포커스가 각각 명확히 다름.
  • About dropdown의 열림·현재 하위 페이지 표시 유지.

작업 3

Q&A 탭: 호버 추가, 불필요한 divider 제거

우선순위 P2

탭은 선택 상태를 하단 파란 선으로 유지하되 비활성 탭에 hover feedback을 추가한다. 빈 목록에서 탭 아래와 empty state 위아래에 중복된 구분선은 제거하고 여백으로 영역을 나눈다.

선택 기준

  • 탭 wrapper의 border-y 제거.
  • empty state의 border-y 제거.
  • Active: accent 글자 + 2px underline.
  • Hover: canvas-soft 배경 + accent-hover 글자.
  • Focus-visible: 기존 접근성 outline 유지.
  • 실제 질문 목록의 행 divider는 스캔에 도움되므로 유지.

수정 대상: src/pages/questions/index.astro. 필터 wrapper의 border-y border-hairline와 empty state의 같은 규칙이 스크린샷의 중복 수평선을 생성.

완료 조건

  • All / Awaiting answer / Answered 모두 hover 반응 존재.
  • 선택 탭은 hover 탭과 모양이 혼동되지 않음.
  • 빈 상태에서 빨간 표시 영역의 수평선이 사라짐.
  • 질문이 있을 때 행 구분선과 pagination 구조는 유지.

작업 4

Contact 링크: 끊기지 않는 텍스트 밑줄

우선순위 P3

전화번호와 이메일의 밑줄이 문자 획을 피해 점선처럼 끊기는 기본 동작을 해제한다. 링크 텍스트 아래에 동일 굵기의 연속선을 사용한다.

구현 방향

  • text-decoration-skip-ink: none으로 획 아래에서도 선을 연속 표시.
  • text-decoration-thickness: 1px로 전화·이메일 굵기 통일.
  • 전역 링크가 아니라 Contact의 두 링크에만 적용.
  • hover에서는 현재 계획대로 2px까지 굵어지거나 색이 바뀌도록 하나만 선택.
  • 긴 이메일이 모바일에서 줄바꿈돼도 각 줄 밑줄이 연속되는지 확인.

  • 숫자·하이픈·@·영문 아래 선이 끊기지 않음.
  • 두 링크의 밑줄 위치와 굵기가 동일.
  • tel:·mailto: 동작과 48px 터치 영역 유지.
  • 375px에서 이메일 오버플로 없음.
