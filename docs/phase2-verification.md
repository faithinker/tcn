## 구현과 감독

게시판, 사용자 관리, 로그인·가입·탐색, 운영 스크립트를 작업자로 분리하고 공용 권한·데이터 계약은 조정자가 관리했다. 작업자 결과를 통합한 뒤 별도 리뷰와 단위·실제 workerd D1·브라우저 하네스로 재검증했다. Orca 실행 식별자는 `run_6e270c36b8d6`이며 구현 4개와 독립 리뷰 1개 작업을 완료했다.

- 총회·임원 게시판: 목록·작성·상세·본인 수정·숨김, 페이지 나누기, 일반 텍스트 이스케이프.
- 계정: 로그인·본인 상태·가입 기반, 기본 준회원, 가입 공개 스위치 분리.
- 결정권자 사용자 관리: 승인·반려·복구·최종 권한 저장. 자기 자신과 기존 결정권자는 서버에서도 변경 금지.
- 감사·고문: 승인 회원 + 임원 게시판 특별 접근. 세미나·미디어·공식 답변·사용자 관리 권한은 부여하지 않음.
- 사용자 변경과 감사 기록은 원자적 배치, revision 경합·requestId 재시도·권한 회수 재검사 적용.
- 릴리스 스위치 기본 off. 신규 비공개 기능 503, 가입 off 시 화면·API 404. 기존 공개 기능과 관리자 기능 유지.

독립 리뷰에서 기존 대소문자 구분 username 로그인이 정규화 때문에 달라지는 회귀를 발견했다. 실패 테스트를 먼저 확인한 후 정확한 기존 username 조회 우선으로 수정했다. 정규화된 대체 조회는 기존 계정이 없을 때만 허용한다.

추가 브라우저 검증에서 JS 없는 form의 기본 GET 전송 위험을 발견했다. 로그인·가입·게시글 폼에서 민감한 필드가 URL에 붙는 실패를 재현한 뒤 명시적 POST/action을 추가하고 재검증했다. JS 없이 가입·게시글 작성까지 지원한다는 의미는 아니며 안전한 실패를 보장한다.

Impeccable 지침은 기존 레이아웃·색상·타이포그래피 재사용과 레이블·오류·모바일 점검에 적용했다. 별도 디자인 체계나 대시보드 스타일을 추가하지 않았다.

헤더 계정 동작 후속 변경: Join / Contact 버튼과 Account 드롭다운을 제거했다. Contact는 독립 탐색 링크이며, 비로그인 상태에서는 Sign in, 로그인 상태에서는 My profile 아이콘(`/account`)과 Log out을 표시한다. 프로필 아이콘에 접근성 이름·툴팁을 제공하고, 로그아웃은 실제 POST 성공 뒤 홈으로 이동한다. 실패 시 계정 표시를 유지하고 오류 안내·재시도를 제공한다. 기존 디자인 토큰을 재사용했으며, `verify:header`의 표시·실패/재시도 검사와 `verify:forum-users`의 실제 프로필 이동·세션 로그아웃 검증을 통과했다. 전체 테스트 878개·타입 검사·로컬 빌드도 통과했다.
