# 개인정보 처리방침 관리 문서

처리방침 본문은 [`src/data/privacy-policy.ko.md`](../src/data/privacy-policy.ko.md)에 있고 `/privacy` 페이지로 공개됩니다. 이 문서는 게시 전에 확인할 사실과 구현 상태만 관리합니다.

- 기준: 개인정보보호위원회 「개인정보 처리방침 작성지침」(2026. 4.)의 항목 구조와 예시.
- 근거 코드: 마이그레이션 0001~0012, `docs/account-lifecycle.md`, `docs/operations-runbook.md`.
- 상태: 코드에 들어 있으며 `main`에 합치거나 배포하지 않았습니다. 가입을 열기 전에 A 항목을 모두 확인합니다.
- 영문본은 한국어 문안이 확정된 뒤에 만듭니다. 법령상 기준은 한국어본입니다.
- `src/data/privacy-policy.test.ts`는 본문에 초안 표시가 남지 않았는지, 세션·기기 쿠키의 이름과 기간, 관리자 접속기록 보관 기간(13개월)이 코드와 같은지 검사합니다.

## B. 구현 상태

| 번호 | 내용                                                                    | 상태                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1   | `/privacy` 페이지, 푸터·계정 화면 링크, 사이트맵                        | 완료. 모든 페이지 푸터와 로그인·가입·재설정 화면에 링크가 있습니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| B2   | 가입 화면의 처리방침 링크, 소속(선택) 안내, 만 14세 미만 가입 불가 안내 | 완료. 나이를 입력받거나 확인하지는 않으며, 그 사실을 3장에 적었습니다.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| B3   | 관리자 접속기록 13개월 보관                                             | 완료. `/admin/users` 열람마다 `admin_access_events`에 한 행을 남기고(계정, 일시, 접속 IP 원문, 열람 조건, 표시된 회원 계정번호·수), 기록에 실패하면 503으로 화면을 닫습니다. 회원 상태·권한 변경은 `user_audit_events.ip`에 처리자 IP를 남깁니다. 두 IP 모두 13개월 뒤 새 열람 기록을 저장할 때 함께 지워집니다. 마이그레이션 0012 트리거가 접속기록의 수정과 395일 안의 삭제를 막습니다. 아직 기록하지 않는 것: 로그인·로그아웃·로그인 실패(후속), 개발자의 운영 D1 직접 접근. 본문 9장에는 하는 조치만 적었습니다. |
| B4   | 비회원 질문·게시글의 영구 삭제                                          | 완료. `docs/operations-runbook.md`의 "Personal-information erasure requests"에 내용을 지우는 SQL 절차를 두었고 로컬 D1에서 검증했습니다. 12장에 지우는 방식을 적었습니다.                                                                                                                                                                                                                                                                                                                                            |
| B5   | 만료 기록의 정리 시점                                                   | 유지. 다음 요청을 처리할 때 함께 지워지며, 4장에 그 사실을 적었습니다.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| B6   | 로그인 시도 제한 키의 해시 방식                                         | 유지. 비밀키 없는 SHA-256이며 본문은 "해시값"으로만 적었습니다. 바꾸면 신뢰 기기 쿠키(90일)가 모두 무효가 되고 잠금 기록이 초기화되므로 별도 작업으로 다룹니다.                                                                                                                                                                                                                                                                                                                                                      |
| B7   | 탈퇴 후 남는 내부 계정번호·역할·시각                                    | 유지. 게시글과 감사 기록이 참조하므로 지울 수 없고, 4장에 "게시글이 남아 있는 동안"으로 적었습니다.                                                                                                                                                                                                                                                                                                                                                                                                                  |
